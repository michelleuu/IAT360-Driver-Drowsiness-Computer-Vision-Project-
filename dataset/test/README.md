# Test Set

Our test set contains 122 annotated images collected by all 4 group members.

Due to privacy concerns (the test images contain our faces) and file size limits, the images and labels are uploaded separately:
- test_labels.zip: label files in YOLO format (included in this folder)
- test_images: uploaded to Google Drive (link below)
